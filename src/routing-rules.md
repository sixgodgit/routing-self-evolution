# 路由规则表

## 优先级从高到低

### 1. 文件类型
```
图片 → MiMo V2 Omni（原生视觉）
文档/文件 → DeepSeek V4（1M 上下文）
```

### 2. 代码意图
```
代码块、编程关键字、报错信息 → DeepSeek V4 Pro
代码审查 → DeepSeek V4 Pro
代码性能分析 → DeepSeek V4 Pro
```

### 3. 深度分析
```
架构设计、系统分析 → DeepSeek V4 Pro
复杂推理、多步推理 → DeepSeek V4 Pro
```

### 4. 文本处理
```
翻译（<1000字）→ DeepSeek V4
翻译（>1000字）→ GPT-5.4
改写/润色/摘要 → DeepSeek V4
```

### 5. 数据处理
```
数据分析/CSV处理 → MiMo V2.5
格式转换 → MiMo V2.5
```

### 6. 创意内容
```
创意写作/博客 → GPT-5.4
营销文案 → GPT-5.4
```

### 7. 默认
```
日常聊天/简单问答 → 我自己（Hermes Agent）
联网搜索 → 我自己（Tavily）
```
