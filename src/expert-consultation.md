# 专家咨询模板

## 咨询触发条件

**什么时候问**：
- 任务类型首次遇到
- 多个规则部分匹配
- 用户要求特殊处理
- 多领域交叉任务

**什么时候不问**：
- 明确的简单任务
- 明确的代码任务
- 明确的图片任务
- 常见任务类型

## 咨询模板

```
任务：[一句话描述]
目标：[期望输出]
约束：[时间/成本/质量要求]
我的判断：[倾向的模型和理由]
请确认或修正。
```

**输入控制**：总 prompt < 100 tokens

## 咨询模型选择

| 场景 | 咨询对象 |
|------|----------|
| **默认** | GPT-5.4 |
| **GPT 不可用** | DeepSeek V4 Pro |
| **简单确认** | MiMo V2.5 |

## token 控制

- 单次咨询输入：< 100 tokens
- 单次咨询输出：< 100 tokens
- 总消耗：< 200 tokens/次
- GPT-5.4 成本：~0.05-0.10 元/次
- 每月最多 5 次

## 咨询记录格式

```markdown
### 咨询记录 #001
- **时间**：2026-06-09 15:30
- **任务**：分析代码性能瓶颈
- **我的判断**：DeepSeek V4
- **咨询对象**：GPT-5.4
- **GPT 建议**：DeepSeek V4 Pro
- **GPT 理由**：性能分析需要深度 profiling 推理
- **结果**：GPT 建议更好
- **积分变化**：-2（咨询）+1（学习）= -1
```
