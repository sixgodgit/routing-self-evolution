# GPT 建议模式库

## 模式分类

### 模式 1：推理深度升级
**触发**：我选择 V4，GPT 建议 V4 Pro
**案例**：架构分析、性能优化、复杂调试
**规则**：涉及多步推理 → V4 Pro

### 模式 2：语言质量升级
**触发**：我选择 DeepSeek，GPT 建议 GPT-5.4
**案例**：长文翻译、创意写作、营销文案
**规则**：需要强语言表达 → GPT-5.4

### 模式 3：成本优化降级
**触发**：我选择 V4/V4 Pro，GPT 建议 MiMo
**案例**：简单数据分析、格式转换
**规则**：任务简单且量大 → MiMo 省钱

### 模式 4：工具选择调整
**触发**：我选择直接处理，GPT 建议用工具
**案例**：需要联网搜索、需要代码执行
**规则**：有更高效的工具 → 用工具

## 模式匹配规则

```
任务包含「分析」「推理」「设计」→ 检查是否需要升级到 Pro
任务包含「翻译」「写作」「文案」→ 检查是否需要升级到 GPT
任务包含「数据」「格式」「转换」→ 检查是否可以降级到 MiMo
```
