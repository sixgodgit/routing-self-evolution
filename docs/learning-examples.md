# 学习案例库

## 案例 #001：架构分析
- **任务**：分析项目架构优缺点
- **我的路由**：DeepSeek V4
- **GPT 路由**：DeepSeek V4 Pro
- **理由**：架构分析需要系统性推理，V4 Pro 更强
- **学到**：架构类任务需要 Pro 级别

## 案例 #002：长文翻译
- **任务**：翻译 3000 字技术文档
- **我的路由**：DeepSeek V4（翻译任务）
- **GPT 路由**：GPT-5.4
- **理由**：长文翻译需要更强的语言理解，保持术语一致性
- **学到**：长文翻译（>1000字）→ GPT-5.4

## 案例 #003：代码审查
- **任务**：审查 500 行 Python 代码
- **我的路由**：DeepSeek V4 Pro
- **GPT 路由**：DeepSeek V4 Pro
- **理由**：代码审查需要深度理解，V4 Pro 够用
- **学到**：代码审查 → DeepSeek V4 Pro（已确认）

## 案例 #004：数据分析
- **任务**：分析 CSV 数据并生成报告
- **我的路由**：DeepSeek V4
- **GPT 路由**：MiMo V2.5
- **理由**：数据分析主要是格式转换和简单计算，MiMo 够用且便宜
- **学到**：数据分析 → MiMo V2.5（省钱）

## 案例 #005：创意写作
- **任务**：写一篇 1000 字的技术博客
- **我的路由**：DeepSeek V4
- **GPT 路由**：GPT-5.4
- **理由**：创意写作需要更强的语言表达能力
- **学到**：创意写作 → GPT-5.4
