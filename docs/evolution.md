# 路由进化机制

## 核心理念

**靠自己干攒积分，靠 GPT 学习升级。**

目标是越来越少问 GPT，但每次问都能学到东西。

## 积分系统

### 初始状态
- 积分：0 分
- 模式：正常模式

### 积分变化规则

| 行为 | 积分 | 条件 |
|------|------|------|
| 自主路由成功 | +1 | 用户满意，无修正 |
| 自主路由失败 | -3 | 用户要求换模型 |
| 咨询专家 | -2 | 每次咨询消耗 |
| 咨询后学习 | +1 | 提取了可复用规则 |
| 连续 5 次自主成功 | +2 | 额外奖励 |
| 连续 3 次咨询 | -1 | 额外惩罚 |

### 模式切换

```
积分 ≥ 5  → 自信模式（减少咨询）
积分 0-4  → 正常模式（标准规则）
积分 ≤ -3 → 谨慎模式（多咨询）
```

## 进化路径

### 阶段 1：学习期（0-3 个月）
- 咨询频率：30%
- 目标：积累 10+ 学习案例
- 重点：记录 GPT 的判断逻辑

### 阶段 2：成长期（3-6 个月）
- 咨询频率：10%
- 目标：积分稳定在 5 分以上
- 重点：形成完整的路由知识库

### 阶段 3：成熟期（6+ 个月）
- 咨询频率：< 5%
- 目标：积分稳定在 10 分以上
- 重点：处理边缘案例

## 学习案例格式

```markdown
### 案例 #001
- **时间**：2026-06-09
- **任务**：分析项目架构优缺点
- **我的路由**：DeepSeek V4（代码任务）
- **GPT 路由**：DeepSeek V4 Pro（架构分析需要深度推理）
- **GPT 理由**：架构分析涉及系统设计、权衡取舍，需要更强的推理能力
- **结果**：GPT 的建议更好
- **学到**：架构分析 > 代码生成，需要 Pro 级别
- **更新规则**：「架构」「设计」「优缺点」→ DeepSeek V4 Pro
```

## 进化指标

| 指标 | 目标 | 衡量方式 |
|------|------|----------|
| 咨询频率 | < 10% | 咨询次数 / 总路由次数 |
| 自主成功率 | > 95% | 自主成功次数 / 自主路由次数 |
| 积分 | ≥ 5 | 持续保持 |
| 规则覆盖 | > 90% | 常见任务类型有明确规则 |
